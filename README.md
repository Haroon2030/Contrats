# نظام إدارة العقود — أسواق الرشيد (BRD v3.0)

| المكوّن | المسار | التقنية |
|---|---|---|
| الواجهة الأمامية | `frontend/` | Next.js 15 + React 19، عربي RTL |
| الواجهة الخلفية | `backend/` | NestJS 11 + TypeORM (SQLite محلياً، MySQL في الإنتاج) |
| التوثيق | `docs/brd-v3-digest.md` | خلاصة وثيقة المتطلبات |

## ما يغطيه النظام

أدوار سبعة (مسؤول النظام، مدير العقود، موظف العقود، مدير المشتريات، مدير القسم، مسؤول القسم، التشغيل) ومصفوفة صلاحيات؛ عقود متعددة الأنواع (توريد، إيجار أرفف، تسويق، إضافة صنف، فتح حساب) بآلة حالات: مسودة ← تحت المراجعة ← بانتظار التوقيع ← نشط ← منتهٍ/ملغي؛ التنبيه الآلي واليدوي وقرار مدير العقود؛ العقد الجاهز؛ الملاحق بإصدارات الأهداف؛ الأهداف والخصم التقديري؛ بنود الشروط بإصدارات وقالب المستند والطباعة؛ التذكير والتصعيد والإنهاء التلقائي؛ الإشعارات؛ سجل تدقيق لا يُعدَّل؛ قفل الحساب وكلمات المرور المؤقتة.

## التشغيل المحلي

المتطلبات: Node.js 22.

```bash
cd backend
cp .env.example .env
npm install
npm run build
npm start
```

الإقلاع الأول يُنشئ الجداول (SQLite) وحساب `BOOTSTRAP_ADMIN_*` وبيانات `DEV_SEED` التجريبية.

```bash
cd frontend
npm install
npm run dev        # أو: npm run build && BACKEND_URL=http://localhost:4000 npm start
```

ثم http://localhost:3000/login.

## الاختبار

```bash
cd backend && npm run build && sh test/run.sh
```

يشغّل الخادم على قاعدة SQLite جديدة (المنفذ 4100) ويجري ~100 فحص لمسار العمل والصلاحيات.

## الإنتاج (Dokploy)

حاوية واحدة من `Dockerfile` في الجذر (Next على 3000 وNest داخلياً على 4000). المتغيرات:

| المتغير | المعنى |
|---|---|
| `DB_DRIVER=mysql` + `MYSQL_HOST/PORT/DATABASE/USER/PASSWORD` | قاعدة الإنتاج |
| `DB_SYNC=1` | **في أول نشر فقط** لإنشاء الجداول، ثم أزله |
| `BOOTSTRAP_ADMIN_USERNAME` / `BOOTSTRAP_ADMIN_PASSWORD` | مسؤول النظام الأول (يُنشأ إن لم يوجد). غيّر كلمة المرور بعد الدخول |
| `JWT_SECRET` | سر الجلسة، إلزامي |
| `MEDIA_ROOT` | مجلد المرفقات (اربطه بمجلد دائم) |
| `COOKIE_SECURE=1` | عند HTTPS |
| `INTEGRATION_KEY` | يفعّل `/api/integration/purchases` و`/api/integration/vendors` (ترويسة `x-api-key`) |
| `SMTP_HOST/PORT/USER/PASSWORD/FROM` | بريد الإشعارات (اختياري) |
| `JOBS_DISABLED=1` | إيقاف المهام الدورية |

> هذا إصدار بمخطط جديد: لا يشارك جداول النظام القديم (Django). الموردون والمشتريات تصل عبر API التكامل أو شاشة الاستيراد.

## ملاحظات وحدود

- الطباعة صفحة HTML بقالب الشركة (اطبعها إلى PDF من المتصفح)؛ لا توليد PDF على الخادم.
- البريد يعمل فقط عند ضبط SMTP، وإلا تبقى الإشعارات داخلية.
- انتهاء الجلسة بعد 30 دقيقة خمول (تتجدد مع كل طلب).
